# MD-Prozess-Tool - Benutzer-Anleitung

## Installation und Start (für End-User)

### Voraussetzungen
- Python muss über das Serviceportal des AFI installiert sein
- Internetverbindung für die Installation der Abhängigkeiten

### Schritt 1: Installation (einmalig)
1. **Doppelklick auf `Install (einmalig).bat`**
2. Warten Sie, bis alle Pakete installiert sind (kann einige Minuten dauern)
3. Bei Erfolg: "Installation erfolgreich abgeschlossen!" wird angezeigt

### Schritt 2: App starten
1. **Doppelklick auf `MD-App.bat`**
2. Die App startet automatisch
3. **WICHTIG:** Schließen Sie das schwarze Fenster nicht, während die App läuft!

### Bei Problemen

#### "Python ist nicht installiert"
- **Lösung:** Bestellen Sie Python über das Serviceportal des AFI
- Python ist eine kostenlose Standardapplikation

#### "Erforderliche Python-Pakete sind nicht installiert"
- **Lösung:** Führen Sie `Install (einmalig).bat` aus
- Falls das nicht hilft: Kontaktieren Sie den IT-Support

#### "Installation der Pakete fehlgeschlagen"
- **Mögliche Ursachen:**
  - Internetverbindung unterbrochen
  - Firewall blockiert die Verbindung
  - Proxy-Einstellungen fehlerhaft
- **Lösung:** Kontaktieren Sie den IT-Support

#### App startet nicht oder stürzt ab
- **Lösung:** 
  1. Führen Sie `Install (einmalig).bat` erneut aus
  2. Falls das Problem weiterhin besteht: Kontaktieren Sie den IT-Support

### Support
Bei anhaltenden Problemen wenden Sie sich an den IT-Support.
